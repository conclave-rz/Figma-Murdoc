# generate-showcase-page

Alias obsoleto: usa **generate-docsite**, que lo reemplaza con un sitio multi-página (Atomic Design), tokens DTCG, código multi-framework, verificación automática y scorecard AI-Ready.

## Qué hacer
Carga `use_skill { skill: "generate-docsite" }` y sigue sus pasos. Si el usuario pidió explícitamente "una sola página de showcase", genera el sitio igualmente y entrega `index.html` como página principal.
