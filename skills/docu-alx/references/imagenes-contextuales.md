# Imágenes contextuales

Incluye una imagen cuando reduzca una ambigüedad real: ubicar una pantalla, explicar una secuencia, mostrar un estado, aclarar una zona de interacción o visualizar una propuesta. No añadas imágenes decorativas sin valor documental.

## Tipos y rotulado

- **Referencia real:** captura o fotografía proporcionada o autorizada. Indica origen y fecha si están disponibles.
- **Diagrama explicativo:** representación simplificada del flujo o relación. Rotula `Diagrama explicativo`.
- **Concepto visual:** mockup o imagen creada para contextualizar una posibilidad. Rotula `Propuesta visual · No representa una interfaz aprobada`.

Nunca fabriques una captura que aparente provenir de un producto real. No agregues personas, marcas, datos o comportamientos no confirmados.

## Obtención

1. Prefiere las imágenes que el usuario haya proporcionado.
2. Para arquitectura, jerarquía o flujo, prefiere diagramas simples y editables.
3. Genera un mockup raster solo cuando el usuario lo pida o cuando aporte valor claro; conserva su rótulo conceptual.
4. Si no tienes acceso a la pantalla o producto, usa un espacio reservado descrito con precisión en vez de inventarlo.

Cada recurso debe tener archivo local o URL autorizada, texto alternativo, pie breve, tipo de evidencia y relación explícita con una HU o con el contexto general. Evita texto esencial incrustado solo dentro de la imagen.
